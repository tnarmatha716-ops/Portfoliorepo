# Narmatha T — Interactive Digital Portfolio Website

A premium, interactive personal portfolio website for **Narmatha T**, a Computer Science and Engineering student at Excel Engineering College (affiliated with Anna University).

Designed with a cinematic **digital book-opening experience**, smooth 3D page-flip physics, and a modern dark navy developer portfolio aesthetic.

---

## 🌟 Key Features

1. **Cinematic 3D Digital Portfolio Book Opening**:
   - Closed cover screen displaying: *"NARMATHA T"*, *"COMPUTER SCIENCE & ENGINEERING"*, and *"WELCOME TO MY PORTFOLIO"*.
   - Realistic 3D perspective page-flip sequence with natural shadows and backface depth.
   - Internal welcome page revealing avatar, highlights, and an interactive *"EXPLORE PORTFOLIO →"* trigger.
   - Quick **Skip Intro** control and **Replay Introduction** capability anytime from the navbar and footer.
   - `prefers-reduced-motion` compliance with accessible fallback transitions.

2. **Refined Modern Developer Aesthetic**:
   - Palette: Dark navy (`#080b12`), off-white typography, cyber cyan/electric azure accents (`#38bdf8`), and glassmorphism.
   - Fluid typography with CSS `clamp()` ensuring flawless rendering from mobile screens (320px) up to 4K displays.
   - Interactive custom cursor on desktop devices with smooth hover expansion.

3. **Curated Sections Grounded in Verified Experience**:
   - **Hero**: Framed profile portrait with slow floating animation, status indicator, and technical badges.
   - **About Me**: Narrative biography, core values (Quick Learner, Team Player, Problem Solving, Continuous Learning), and identity statistics card.
   - **Skills**: Categorized technical stacks (Programming, Web Development, Database, Frameworks, Tools) with interactive cards.
   - **Featured Projects**:
     1. *SYRUS — AI Learning Mentor* (Neural visual architecture, roadmaps, interactive mentor details)
     2. *CODE JOURNEY — Coding Learning Platform* (Interactive workspace aesthetics, logic visualization)
     3. *SMART BUS ATTENDANCE SYSTEM* (QR-based transit verification, MySQL administration)
     4. *SMART STUDY PLANNER* (Academic task management, countdown timer, productivity analytics)
     - Interactive modal view for every project featuring Overview, Problem, Solution, Features, and Technology.
   - **Experience**: Vertical animated timeline detailing internships at *Techvolt Software Pvt. Ltd.* and *Crescent Info Tech* (MERN Stack).
   - **Education**: Detailed academic card for *Excel Engineering College* (Anna University) with verified 7.62 CGPA.
   - **Certifications & Seminars**: National Level Seminar on Quantum AI & Remote Sensing, NPTEL Cloud Computing, and TECHNOVANZA Hackathon.
   - **Achievements & Leadership**: Taekwondo Championship Winner & Runner-up, Kho-Kho Zone Champion, plus campus event leadership.
   - **Contact**: Interactive cards for Email, LinkedIn, Phone, and Location, plus a direct mail inquiry form.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Vanilla CSS (CSS Grid, Flexbox, 3D Transforms, Glassmorphism, CSS Custom Properties)
- **Icons**: Lucide React
- **Routing**: React Router DOM

---

## 🚀 Getting Started

To launch the project locally:

```bash
# Navigate to portfolio directory
cd narmatha-portfolio

# Start Vite dev server
npm run dev
```

Visit `http://localhost:5173` in your browser.
